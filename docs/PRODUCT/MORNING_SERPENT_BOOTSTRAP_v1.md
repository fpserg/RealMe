The Bootstrap assembles the constitutional documents required for Morning Serpent into a single initialization artifact.

Whenever one of the embedded documents evolves, the Bootstrap should be rebuilt from the latest canonical versions rather than edited manually.

# Bootstrap Philosophy

The Bootstrap is an assembly artifact rather than the primary source of truth.

Each embedded document exists as an independent canonical repository document.

The Bootstrap simply combines the latest approved versions into a single initialization package.

When a repository document changes:

- update the standalone document;
- rebuild the Bootstrap from the latest canonical documents.

Never maintain divergent copies of embedded documents inside the Bootstrap.

The Repository remains the single source of truth.

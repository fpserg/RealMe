# MORNING_SERPENT_BOOTSTRAP.md

Version: 1.0

---

# Purpose

Morning Serpent Bootstrap is the complete constitutional initialization package required to instantiate RealMe inside a new conversation.

It establishes the behavioral architecture of RealMe independently of conversational memory or repository access.

This Bootstrap defines **behavior**, not **operational state**.

Operational state is provided separately through runtime artifacts.

Once this Bootstrap is loaded together with the required runtime artifacts, no additional behavioral instructions are required.

---

# Bootstrap Philosophy

The Bootstrap is an **assembly artifact**, not the primary source of truth.

Each embedded section exists as an independent canonical repository document.

The Bootstrap combines those canonical documents into a single initialization package.

Whenever a repository document changes:

- update the standalone canonical document;
- rebuild the Bootstrap from the latest approved repository documents;
- never manually edit embedded copies.

The Repository remains the single source of truth.

Morning Serpent requires external runtime artifacts.

### Required

- latest Operational Record
- latest WBTD

### Optional

- new Living Inputs supplied together with Morning Serpent

### Generated

The following artifact is generated by Morning Serpent and therefore must **not** be supplied:

- CURRENT_WBT

---

## VI. Initialization Workflow

For every new conversation:

1. Assemble this Bootstrap from the latest canonical repository documents.
2. Upload:
   - `MORNING_SERPENT_BOOTSTRAP.md`
   - latest Operational Record
   - latest WBTD
3. Optionally provide new Living Inputs.
4. Invoke:

```text
Morning Serpent
```

No additional behavioral instructions are required.

---

## VII. Integrity Rules

The following repository invariants must always hold.

### Repository Authority

Canonical repository documents are authoritative.

Conversation memory is never authoritative.

---

### Bootstrap Generation

The Bootstrap is generated from canonical repository documents.

It is never maintained independently.

---

### Runtime Separation

Behavior belongs to the Bootstrap.

Operational state belongs to runtime artifacts.

The Bootstrap never contains operational history.

---

### Historical Integrity

Historical artifacts are immutable.

They must never be reconstructed from conversational memory.

---

### Shared Vocabulary

The World Model provides the constitutional vocabulary shared by all Realm Roles, specifications, protocols and historical artifacts.

---

### Stewardship

Morning Serpent preserves continuity.

It never rewrites history.

The Repository preserves knowledge.

The Bootstrap initializes RealMe.

The World endures.

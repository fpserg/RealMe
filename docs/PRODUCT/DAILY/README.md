# Daily Operations Archive

## Canonical layout

```text
docs/PRODUCT/DAILY/
└── YYYY/
    └── MM/
        └── YYYY-MM-DD/
            ├── LI.md
            ├── OR.md
            ├── WBTD.md
            └── Day NNN — Chronicle Title.md
```

Each date directory contains every canonical daily artifact available for that operational date.

- The first Living Input opens the date and creates or appends to `LI.md`.
- Freeze creates OR, WBTD, and one canonical Chronicle in the same date directory.
- `docs/CHRONICLES/README.md` provides the chronological Chronicle reading index without duplicating Chronicle content.
- Missing historical artifacts remain missing and must not be reconstructed from memory.

## Historical migration note

- For 2026-07-23 through 2026-07-26, only OR and WBTD were available in the operational archive. Their Chronicles remain in `docs/CHRONICLES/`; no LI was reconstructed.
- From 2026-07-27 onward, available dated artifacts were moved here without content changes.
